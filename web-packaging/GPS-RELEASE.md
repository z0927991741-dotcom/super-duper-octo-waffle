# 夢境修補員｜網頁試玩 v23 同版 Windows／Android

保留 Q 版向量地圖、男女玩家、圓形搖桿、固定 30 公尺圈、沿道路指引、三位 NPC 記憶挑戰、去背成功圖與可開關的走路音樂。沒有自動前往，不切換回 Godot 介面。

## 安裝與操作

- Windows 10／11 x64：解壓整個 DreamMender-GPS-Windows-v0.23.zip，執行資料夾內的 DreamMender.exe。預設且明示模擬定位，用搖桿或方向鍵沿道路移動；此 Windows 版不提供真實 GPS。
- Android 7.0 以上：安裝 DreamMender-GPS-v0.23.apk。這是已簽署的測試 APK，沿用 v0.21 OSM 測試包的應用程式 ID 與測試簽章，versionCode 升為 23；不是商店正式發行簽章。
- Android 可使用模擬定位，或選「GPS 定位」並按「啟用／重試定位」。請允許定位；只給約略位置時可能因精度不足而無法抵達。
- 頁首「走路音樂」預設關閉，開啟後移動播放，停步或進入對話時淡出；與音效開關分開。
- 道路資料與向量底圖仍需網路。沒有道路資料時暫停模擬移動並提示重試，不改成穿越建築物的自由移動。不支援向量繪製時顯示道路簡圖。

## 存檔與安全入口

同平台保留既有 sim／real／field 獨立存檔及固定圈；獎勵不重複發放。Android 同 ID、同簽章更新可保留應用程式資料；Windows 使用原有本機資料位置。一般瀏覽器、Android 與 Windows 存檔彼此獨立，沒有自動同步或搬移。

三個景點的政府參考座標不等於安全入口；入口仍待現場證據查核，正式景點任務保持鎖定。可先用模擬模式，或 Android「私人測試點」驗證自己的 GPS 任務。私人測試成果不代表完成正式景點任務。請在可合法步行、能安全停留的位置停步後操作。
