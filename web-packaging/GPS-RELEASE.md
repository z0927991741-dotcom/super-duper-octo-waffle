# 夢境修補員 GPS 網頁同版測試包 v0.21

Windows：解壓整個 ZIP，執行 DreamMender.exe。預設且明示模擬定位，圓形搖桿或方向鍵移動；Windows GPS 權限不開放。

Android：安裝 DreamMender-GPS-v0.21.apk，選 GPS 定位並按啟用／重試定位授權。此包使用既有 OSM 測試應用程式 ID 及測試簽章，不是正式發行簽章。同一 ID 且同簽章可更新並保留該測試應用程式資料；一般網頁、其他應用程式 ID 與 Windows 進度分開保存。

兩平台嵌入與網頁相同的 HTML。保留 Q 版地圖、男女角色、圓形搖桿、30 公尺圈、NPC 記憶挑戰及各模式獨立存檔。目的地以直線顯示方向及直線距離；直線不代表可步行通過，模擬角色仍受道路限制。

底圖仍需網路。完整 OSM 道路資料尚未隨版本打包，成功取得的道路資料會保存在瀏覽器／應用程式內；未取得完整路網時使用圖塊道路辨識備援，可能仍有辨識限制，不能宣稱所有道路均通行。

正式三景點入口尚待使用者提供現場資料核對，正式任務仍鎖定；可用私人 GPS 測試點測試實際定位、抵達與玩法。私人測試成果不代表完成正式景點任務。

Windows 實機執行、Android 手機安裝與戶外 GPS、三個現場入口均尚未實機驗證。此為作業開發測試包，尚未完成全部驗收要求。
