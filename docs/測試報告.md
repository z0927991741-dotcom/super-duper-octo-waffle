# v0.18.0-preview 測試報告

日期：2026-10-15。這是待實機驗證的測試版，尚未符合完整作業繳交條件。

## 已通過

- 網頁核心測試：23 項通過，0 項失敗。
- Chromium 端到端：本次選跑 4 項，涵蓋三關流程、答錯重試、存檔、唯一獎勵、角色選擇、縮放及模擬 GPS 拒絕／重試／精度／逾期。
- 網頁獨立單檔快取後離線重新開啟，進入角色選擇與探索成功。
- Godot 規則測試、啟動自測通過。
- Godot Linux 圖形介面自動測試：三個 NPC、對話特寫、三關重試與通關、存檔、防重複領獎及模式隔離通過。到點測試直接設定測試位置；道路移動另以規則測試驗證。
- Windows x86_64 EXE 匯出成功，內含 PCK 與素材。
- Android API 24+ APK 建置成功，包含 ARM64／x86_64；定位權限、GPS 插件與直式設定已做靜態檢查。
- APK 使用私人金鑰簽署；apksigner v2／v3 驗證與 zipalign 16 KB 對齊檢查通過。金鑰與密碼未納入原始碼及下載包。

## 未驗證／未完成

- Windows 實際執行、Android 實機安裝及音效播放。
- Android 戶外 GPS、授權視窗生命週期、不同品牌省電行為、三點抵達證據。
- 三個正式座標及安全步行入口查證，正式任務目前保持鎖定。
- 學號姓名與實測照片／影片。不得把自動測試當作戶外實測證據。
