# Codex 協作摘要與素材來源

## 協作摘要一：瀏覽器原型與互動修正

依使用者需求建立模擬經緯度、道路限制、距離解鎖、4／5／6 個圖案記憶挑戰、分模式存檔與唯一任務獎勵。依測試修正抵達按鈕、連續完成不同任務、方向提示遮擋角色等問題；加入 NPC 談話、逐段臉部特寫與每次開始顯示選角。

## 協作摘要二：原生雙平台與定位

使用 Godot 4.6.3 製作原生 2D 版本，將任務與美術設定由網頁來源匯出為 JSON。以 GDScript 分離距離規則、道路移動、記憶挑戰與存檔；Android Java 模組使用前景 GPS、精確位置權限、精度與時間判定。Windows 明示模擬，兩模式進度分開。執行 Godot 自動流程與瀏覽器回歸測試；實機與正式座標查證狀態另列。

## 素材

- 三地標建築插畫、男女全身像／步行圖、三位 NPC 立繪／步行圖：使用者在本對話提供的 Gemini_Generated_Image 系列 ZIP 與圖片。去背衍生圖由影像工具製作，原始參考仍保留於附件；專案使用衍生 PNG。
- 地圖：程式繪製的 Q 版示意，參考使用者提供的 Google Maps 截圖之相對布局；不內嵌 Google Maps 圖磚，不能作為真實導航或已查證座標證據。
- NPC 與夢境情節：遊戲創作；文化敘述與來源連結集中在 src/stories.js、src/npc.js，以及原生 data/game.json。
- 字體：Noto Sans TC，SIL Open Font License；授權全文 native/assets/FONT-LICENSE.txt。
- 引擎：Godot Engine 4.6.3，MIT；原生發行包附引擎授權。
- 音效：程式合成短音，無外部音檔。
