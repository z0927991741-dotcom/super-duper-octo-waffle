# 操作與實測

## Windows

解壓 Windows 壓縮檔，執行 DreamMender.exe。不需要安裝 Godot。
首頁 → 選角色 → 模擬試玩。使用 WASD／方向鍵或拖曳圓形搖桿沿道路走動；按 ＋／− 縮放。進入範圍後按「修補夢境」。

## Android

下載 DreamMender.apk，從裝置下載資料夾開啟並依系統提示允許該來源安裝。首次開始為真實定位模式。點「啟用／重試定位」後，允許使用期間的精確位置；遊戲不要求背景定位。切到背景會停止定位，回來後需重試。

正式座標未查證時會明示鎖定，APK 的安裝成功不代表實地任務已完成。可按「模擬試玩」測試美術與挑戰，其完成紀錄與真實模式分開。

## 共通規則

- 每次從首頁進入都顯示選角，預選上次人物。
- 任務順序自由，靠近哪個地點即可修補。
- 圖案展示時不能輸入。答錯可重新觀看；音效可關閉。
- 收集三個不同 ID 的碎片即通關。重玩不重複領取。
- 進度存在本機；解除安裝／刪除應用資料會清除。瀏覽器版與原生版不會自動互相匯入進度。
- 重設需二次確認，只清除目前模式。
- Q 版圖是遊戲示意，不是導航；實地模式不把真實位置投影到未校準的示意圖。

## 必填的戶外驗證紀錄

目前以下項目皆「尚未實測」，不能提前勾選完成。

| 任務 | 正式座標與來源 | 入口安全／開放狀態 | GPS 精度、時間 | 抵達前／後畫面 | 重進無重複獎勵 |

逐點流程：
1. 記下手機型號、Android 版本、測試日期、APK 版本。
2. 在 30 公尺範圍外截圖：距離、定位精度、按鈕尚未解鎖。
3. 安全步行到公開入口附近，停步後截圖：有效定位且修補按鈕可按。
4. 完成挑戰，截圖碎片增加；離開再進入並重玩，確認碎片不重複。
5. 關閉再開啟應用，確認進度與角色保留。
6. 拒絕權限、僅提供概略位置、關閉 GPS、切到背景後返回，確認提示與重試；不得偷偷轉為模擬。
7. 完成三點並錄下通關畫面；將照片／影片放在繳交 ZIP 的「實測證據」資料夾。

Android 模擬器、測試座標、桌面自動測試不能代替這份戶外證據。
