# 夢境修補員｜設計作業單

學號：待填　姓名：待填　遊戲名稱：夢境修補員

使用軟體：Codex ＋ Godot 4.6.3（原生版）；另保留瀏覽器原型。

## 核心玩法

玩家扮演夢境修補員，步行前往屏東三個文化景點。Android 讀取玩家授權的真實 GPS；距離任務點 30 公尺內、精度不超過 25 公尺且定位資料不超過 15 秒，才能開始該地點的 NPC 互動與記憶挑戰。Windows 使用明示的模擬定位，沿道路移動，沿用距離與挑戰規則。完成後取得唯一碎片，讓夢境恢復色彩。

現況：上述 GPS 程式已實作；正式座標尚待來源查證與戶外入口實測，實地任務保持鎖定。不得將目前測試座標填作真實座標。

三個地點：① 屏東美術館外　② 阿猴城門（朝陽門）　③ 屏東書院外。

## 動作分解

收到附近地點與距離提示 → 沿道路移動 → 進入有效抵達範圍並停步 → 點「修補夢境」 → 與 NPC 談話 → 觀看 4／5／6 個圖案的閃爍順序 → 依序按圖案 → 獲得碎片並恢復色彩 → 前往其他未完成地點。

三個任務可自由順序完成。挑戰開始後不因暫時 GPS 飄移而中斷。

## 成功與重試

勝利條件：在同一模式下完成三個不同任務，集齊三塊碎片。

答錯：友善提示，可重新觀看同一序列並重試；不用重新走到任務點。
定位失敗：顯示原因與重試；不自動改為模擬定位。
再次完成同一任務：可重玩，但不增加碎片。
