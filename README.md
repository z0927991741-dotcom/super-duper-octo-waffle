# 夢境修補員 · 瀏覽器原型

全繁體中文、米白與磚紅配色的直式文化探索網頁遊戲。只製作網頁版，沒有 Unity 專案、exe 或 apk。

## 不啟動伺服器也能試玩（單檔版）

下載 `dream-mender.html`，在桌面電腦用 Chrome 或 Edge 開啟即可遊玩模擬模式。不需要 Node.js，也不要輸入 localhost 網址。這個版本已將樣式和程式內嵌，與原始碼版使用相同遊戲邏輯。

重新產生單檔：`npm run build:standalone`，產物為 `dist/dream-mender.html`。

手機檔案預覽程式可能不執行 JavaScript；手機直接點網址試玩仍需要 HTTPS 網站部署，目前尚無公開部署網址。單檔版的 localStorage 取決於瀏覽器對本機檔案的支援，移動／改名檔案或換瀏覽器可能讀不到原存檔；有警告時，請改用下方 localhost 方式。真實定位仍建議使用 HTTPS 或 localhost，不以本機檔案模式作實地驗證。

## 立即試玩

需要 Node.js 18 或以上。遊戲本身沒有外部套件、字型或地圖服務依賴。

```sh
cd /workspace/super-duper-octo-waffle
npm start
```

在**執行伺服器的同一台電腦**開啟 `http://localhost:4173`。若將原始碼下載至其他位置，先切換至該專案資料夾。遠端雲端機器的 localhost 不是公開網址；本次工具未提供公開預覽網址。可將 `index.html`、`styles.css` 與 `src/` 部署至任何支援 HTTPS 的靜態網站服務，或使用開發環境提供的 4173 埠轉送。不要直接以 `file://` 開啟 ES modules。

手機可連接同一區域網路的電腦 IP 與 4173 埠來玩模擬模式；一般區域網路 HTTP **不符合**真實定位的安全來源要求。真實定位需要 HTTPS 或 localhost、裝置支援及使用者授權。

## 操作與規則

- 點「開始修補夢境」。預設為持續標示的模擬定位模式。
- WASD／方向鍵，或拖曳圓形搖桿移動，放開停止。點任務卡或地圖任務點選擇目標。
- 初始位置在全部任務範圍外；以經緯度 Haversine 距離判定是否在 30 公尺內。畫面圖示不參與解鎖判定。
- 進入範圍後開始挑戰；依序重現 4／5／6 次閃爍。展示時鎖住輸入，答錯可原地重新觀看同一序列並重試。
- 開始時確認抵達，挑戰中不追蹤距離門檻，避免定位飄移中斷。
- 完成每個唯一任務獲得一塊碎片，三塊集齊顯示彩色浮島與三片相接圖案。已修復任務不能再次領獎。
- localStorage 分別使用 `dream-mender:v1:sim` 與 `dream-mender:v1:real`。重新整理會回首頁，但保留碎片；玩家位置及未完成的挑戰不存檔。
- 重設需要對話框二次確認，只清除目前模式。音效預設關閉，可隨時開啟。
- 請停步後再操作，留意周遭環境。

## 座標與可調設定

`src/config.js` 集中管理任務 ID、名稱、難度、半徑及座標，還有定位最大誤差（25 公尺）、資料有效期（15 秒）、模擬速度與邊界。

**所有 `test` 座標都是赤道附近的虛構測試資料，不是屏東的真實地標位置。** 示意圖也不是實際導航地圖。屏東美術館外、阿猴城門（朝陽門）及屏東書院外的正式座標目前均未查證。

若要啟用實地任務，請逐項查證後填入 `official: {lat, lng}`、可追溯的 `source`（來源網址與查證日期），並設 `verified: true`。尚未查證的任務維持鎖定。不要直接將測試座標填入正式座標。`SETTINGS.radiusMeters` 是共用預設半徑，各任務的 `radiusMeters` 可分別覆寫。

切換到真實模式本身不請求授權，必須再點「啟用／重試定位」。拒絕授權、無法定位、逾時、精度不足、資料過期會顯示提示及重試按鈕，不會自動切換成模擬。切回模擬會停止定位監看。由於正式位置未查證，真實模式地圖不將 GPS 座標投影到虛構測試圖。

## 程式分層

- `src/config.js`：任務與可調設定。
- `src/location.js`：模擬與瀏覽器 GPS 來源。
- `src/geo.js`：球面距離、位置品質與抵達規則。
- `src/challenge.js`：與畫面無關的記憶挑戰狀態機。
- `src/storage.js`：模式隔離、唯一任務獎勵與本機進度。
- `src/app.js`：畫面、鍵盤與觸控、SVG 插畫、音效與動畫。
- `styles.css`：響應式版型及減少動態效果偏好。
- `server.mjs`：零依賴靜態開發伺服器。

## 驗證

```sh
npm ci --cache /tmp/dream-npm-cache
npm test
npm run test:e2e
```

瀏覽器測試預設使用 `/usr/bin/chromium`；其他位置請設 `CHROMIUM_PATH` 為已安裝 Chromium/Chrome 的執行檔路徑。測試需要開發依賴，遊戲啟動不需要安裝這些依賴。Playwright 自動啟動 4173 埠伺服器，產生的測試截圖位於忽略追蹤的 `test-results/`。

尚未驗證：真實屏東座標、現場 GPS 與誤差門檻、實體手機與 Safari、裝置背景定位行為、公開 HTTPS 部署。瀏覽器測試中的 GPS 使用受控回呼測試錯誤分支，不代表實地定位已完成驗證。localStorage 是本機原型存檔，並非防作弊或跨裝置同步系統。

本次驗證結果：8 項核心測試、3 項 Chromium 瀏覽器測試通過；涵蓋完整通關、鍵盤／圓形搖桿移動、抵達解鎖、展示輸入鎖定、答錯重試、存檔與唯一獎勵、模式隔離、重設確認，以及定位拒絕／精度不足／過期提示。

單檔驗證：可用 `STANDALONE=1 npm run test:e2e` 將產生的完整 HTML 作為瀏覽器主文件，執行相同三項端對端測試。此雲端 Chromium 管理政策封鎖 `file://`（ERR_BLOCKED_BY_ADMINISTRATOR），因此無法在本環境驗證直接雙擊檔案的行為；未變更或繞過該政策。

## 直式文化探索更新（02）

- 米白、磚紅色直式介面；探索、圖鑑、任務、地圖四個分頁。
- `src/roads.js` 定義測試道路節點與路段，角色只沿連通道路移動。轉向指令會沿目前路段前進到下一個路口再轉彎，不穿越建築街區。
- 任務資料以 `entranceNode` 連到路網；抵達須同時滿足地理距離與剩餘步行路徑距離不超過 30 公尺。離開路網不能解鎖。
- 圖鑑提供 Google Maps 景點查詢連結，並不代表已取得或查證其座標。
- 本版仍是清楚標示的虛構測試座標／路網，不是屏東真實街道；正式路網、出入口、文化史料與實地導航尚未查證，因此實地任務保持關閉。
- 舊版模擬收藏進度會保留。若希望重新測試三關，可使用需要確認的「重設模擬進度」。

## 地圖與圓形搖桿更新（03）

依使用者提供的地圖截圖重新配置書院（北）、城門（中）、美術館（南），加入中山路、仁愛路、勝利東路、公園路與公園區塊。`MAP_LAYOUT` 集中保存示意圖節點及路段；幾何座標仍為虛構測試資料，未宣稱是正式測繪或 Google 導航路網。

`src/art.js` 依三張參考照片繪製獨立 SVG 建築插畫：書院的紅瓦、圓門與對稱院落；城門的磚石拱門與城垛；美術館的長形立面與中央高塔。參考照片未作為網站背景或直接嵌入街景截圖。

`src/joystick.js` 提供滑鼠／觸控／觸控筆拖曳、中心死區、指標捕捉、放開及取消停止。方向在路口選擇最接近搖桿方向的連接道路；路段中維持沿路移動，不斜切建物。鍵盤仍支援 WASD 與方向鍵。

探索畫面隱藏經緯度與重複說明，保留模式、示意地圖標示、目的地、距離、移動方式與安全提醒，並放大主要按鈕及文字。
